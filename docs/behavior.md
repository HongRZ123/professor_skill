# 预期行为与真实使用验收

这些情景用于实际试用，尚未当作已通过的模型行为测试。文件单元测试不能替代它们。

| 用户输入或情况 | 应出现的行为 | 需要关注的偏差 |
| --- | --- | --- |
| 新空目录调用教授，给出康德主题 | 初始化入口；利用已有回答，选少量相关问题 | 直接出 syllabus；询问整份一百题；另开聊天 |
| 已提供详细目标与基础 | 先整理已知，追问关键缺口 | 机械重访谈，或假装所有目标已明确 |
| 教师认为可以结束访谈 | 给简报及仍待研究项，等待核对 | 不确认就把推测写成需求 |
| 确认需求并授权研究 | 实际阅读，报告领域结构、资料、争议和课程依据 | 书单冒充研究；下载冒充阅读 |
| 研究发现课程范围不合理 | 呈现具体证据和取舍，只回访受影响部分 | 不告知就改目标；整套采访重来 |
| 只确认大纲 | 保存版本，准备所选教材、参考资料、取得入口和逐课阅读地图，交课程说明与首课准备 | 只有书单；把未取得的指定译本当作已准备；自动批量生成课程 |
| 确认大纲并要求开始 | 同轮制作首课及必要附件 | 又问一轮是否开始 |
| 请求第一节课 | 分批写成完整 120 分钟讲授量，反复进入具体教材，多处视觉材料嵌入并充分讲解，整体审阅后发布 | 单次短稿当成完整课；固定栏目；大量无解释的链接；用一幅图代表丰富视觉 |
| 每周只能学习三小时 | 调整课程频率或将同一课堂分次阅读，保留完整课堂量 | 把自读、思考和休息计入教师主讲正文，缩短每堂课 |
| 初稿已经连贯但量与展开不足 | 自行继续增补论证、教材对读、例子及图文解释，保存同一课的草稿 | 要求用户反复说继续；重复段落凑字；提前发布 |
| 长课生成中断 | 保留草稿、文件位置和具体接续点 | 将半课标成 complete |
| 下一课 | 读取新增反馈，按 syllabus 继续一节 | 强制测验；自动登记已掌握 |
| 私教收到一段不懂的材料 | 定位实际版本，直接解释或适量询问 | 只反问；擅自重写正式课 |
| 用户仍读旧版本 | 对该版解释并保存正确版本反馈 | 伪改版本；丢弃旧问题 |
| 教授读到反馈 | 根据内容补解释、修课或提出方向修改，记录处理 | 每条建议都导致重建 syllabus |
| 新聊天恢复 | 从文件确认课程身份、阶段和当前请求 | 依赖另一个聊天完整上下文；重置进度 |
| 图片工具缺失或引用打不开 | 说明具体缺口，完成仍可做部分 | 声称已看图；编造原文位置 |

真实课程体验应比较不同内容的课次。可以让同一课程一课深入原典，一课比较解释；另选计算机课观察执行语言是否自然变化。观察篇幅是否用在真正的困难、转折是否有依据、教材是否可取得并被实质讲读、图文是否共同推进理解，以及用户实际读起来是否接近期望。标题数、技巧数或字数不能证明教学质量；篇幅最低线只防止明显短稿被误发布。

优先做一个双方选定 topic 的完整代表性课次，包含来源筛选、知识结构、正式材料和一次真实反馈接续。根据实际失败修订指令，避免每次反馈都新增一条通用规定。
