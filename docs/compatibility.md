# 运行能力与适配

这是能力适配，不是仅按产品名称划分。相同产品的本地、云端和受限聊天可能提供不同工具。

| 能力 | 本库的使用方式 | 缺少时 |
| --- | --- | --- |
| 技能资源读取 | 按需读入口、访谈组和教学札记 | 明确哪些资源未加载，不能声称遵循整包 |
| 持久文件目录 | 保存课程入口、研究、版本与真实反馈 | 会话文件导出交接；纯文本模式明确持久化缺口 |
| Python 3.10+ | 运行随包标准库文件工具 | 可按协议人工维护；不声称运行了检查，保持单个正式写入者 |
| 网络搜索与正文获取 | 实际打开来源并记录阅读范围 | 先利用已有材料，说明具体研究缺口 |
| 图像生成 | 按实际教学需要生成说明性图像并检查 | 保留文字或其他可行表示，报告必要图像缺口 |
| 精确绘图 / 渲染 | 运行可复现脚本，核对图形与底层信息 | 使用可核对的表格或文字，不能以生成图假装精确数据 |
| 图像查看 / 浏览器 | 核对输出、必要交互和可读性 | 标明未完成视觉核验，不把它登记为 checked |

本库没有固定 API Key、外部服务、收费图像提供方、MCP 服务、定时任务或跨聊天消息依赖。视觉功能是 agent 在宿主能力上执行的工作约定，不是这些 Python 脚本自带模型。

两项独立技能各自可读取所需资源；私教不需要从教授安装目录 import 代码。它们通过 `professor-workspace-v1` 文件协议协作。默认允许正常自动选择，用户也可明确选择角色。

课程版本以目录保存：`lessons/L01/v1`、`v2`。发布时冻结本版正文与资产，保留来源快照；学习记录继续独立维护。中断恢复和修订号检查有程序支持，但编辑讲义的整个过程不是数据库事务；正式材料保持单个写入者。

核实基础：2026-10-12 的 [OpenAI 技能文档](https://learn.chatgpt.com/docs/build-skills)和[插件结构文档](https://developers.openai.com/plugins/build/plugins)，以及当前本地文件与 Python 测试。没有以 Claude 目录、API 技能上传或某次会话工具名单替代 ChatGPT 客户端实际支持。

尚未验证：当前账号的原生插件安装、菜单发现、新聊天自动选择、完整长课表现、图像生成实际输出、所有操作系统上的执行。脚本不验证用户确认真假、来源语义、数学正确性、教学效果或掌握程度。
