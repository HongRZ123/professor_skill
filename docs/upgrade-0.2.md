# 0.2：恢复完整课堂的交付要求

真实试用的康德首课有来源、课前导引和课后回读说明，但主读中文译本没有取得，也没有课程材料包；正文约一万一千六百个汉字，未嵌入图表或图像，却已通过旧文件检查并发布。阅读安排存在，学生能够实际使用的教材准备仍不足。

旧指令把两小时写成可校准体验，题库更有“不把两小时当硬要求”；视觉只作为可选择附件；检查器验证文件引用，却不检查课堂量和材料准备。这些条件允许 agent 在没有完成用户核心要求时收束。此处分析依据实际文件，不能由此断言模型内部究竟因为哪一句话停止写作。

本版明确每课完整 120 分钟讲授量，周预算只控制一周多少课和学习跨度。编写预算及防缩水最低量写入交付约定；不是以字数证明深度。多次写入、回看薄弱处并增补同一课堂成为正常制作方式。教材要实际准备、定位并反复进入正文；视觉主动制作、嵌入并充分讲解，不能以文字也能说明为由全部省略。

新增材料包与逐课阅读地图要求。ready、authoring_lesson 和新发布分别核对相应材料；发布同时核对正文量、callback 定位与视觉嵌入。只有明确的用户规格更改可覆盖标准篇幅。脚本不能判断用户确认真假或图解质量，相关字段不能由 agent 自行编造。

## 已有课程怎样继续

课程格式仍为 professor-workspace-v1；旧 state、课程身份、访谈、大纲、已发布讲义与用户笔记保留，不自动清空迁移。新检查可以审查旧课的交付缺口，检查失败不表示文件损坏。

回到原课程聊天时明确重新读取已安装 professor 的当前 SKILL.md，再读取该课程入口和状态。先补材料包与具体阅读，再对未达标课次创建新版本，例如 L01/v2，连续增补直至完成完整课堂；不要直接进入下一课。已经确认的课程方向可沿用，不要求重新访谈。

可使用这样的请求：

> 请重新读取当前 professor skill。保留这门课已有的需求与大纲，按新版要求补齐主教材、参考资料和逐课阅读地图。随后将第一课重做为新版本，达到完整 120 分钟的讲授量，充分展开教材对读和多处图文讲解；可分多次写入持续完善同一课，完成后再发布。保留旧版。

本次修订只更新技能与分发包，并用原课进行只读检查；没有在使用者课程目录里重写教材、讲义或状态。新版本仍需以一份实际完整课堂进行体验验收，自动测试不能替代它。
