单元测试还覆盖：缺失确认引用无法前进、未知来源或读取范围缺失拒绝发布、精确数据图必须保留数据与脚本、交互材料必须有后备文件、已发布正文被改动可检测、来源登记继续增长不误伤已发布课、私教可反馈真实旧版本且不改教授状态。脚本无法确认一张图真的被正确检查，也无法确认记录的用户决定或阅读行为真实发生。

0.2 新增回归覆盖：短讲义不发布；书目不能替代材料包；不可用主教材不能进入 ready；课后阅读不能空缺；资产必须实际嵌入；教材 callback 位置必须在正文存在；缩短规格需要可追溯记录；代码、表格和块引文不能补正文计数；行内 Mermaid 必须匹配保留的源文件。长正文测试夹具刻意使用重复文字，仅用于触发篇幅边界，不是合格讲授样例。

## 真实首课的只读回归

原康德课程的第一课通过 0.1 文件检查。新检查拒绝同一课：缺少 materials 下的材料入口、阅读地图及登记；主讲正文计数 11,490，低于默认 24,000 的防缩水线；没有嵌入视觉对象，也没有新交付定位字段。原课有课前与课后导引，不能把问题描述成完全没有阅读安排；缺的是可使用的主教材准备及材料包。新检查揭示缺项，不能证明所有已有论述都不充分。

本轮未改动原课程、需求、大纲或学习状态。完整课堂的真实内容与视觉体验仍待验收。

## 执行中遇到的问题

首次测试使用系统临时目录，当前 Windows 沙箱允许创建临时根却拒绝在其中继续写入及清理，产生环境权限错误。测试改用库内 build/test-workspaces，清理前核对绝对路径边界；随后全部通过。另一次早期命令 stdout 未指定 UTF-8 出现中文显示乱码，文件内容经 UTF-8 读取正确；使用命令已明确 `-X utf8`。

命令行直接下载 schema 被网络沙箱拒绝，随后用实际可用网页工具取得完整 JSON，经去除网页行号后解析保存到构建区，再执行 jsonschema 校验。schema 来源为[Agent Plugins 1.0.0](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json)，由 [OpenAI 打包文档](https://developers.openai.com/plugins/build/plugins)指明。没有绕过账号或网站权限。
