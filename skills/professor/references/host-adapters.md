# Codex 与 ChatGPT 的运行适配

先看当前工具与实际文件能力，不由产品名猜测。技能提供工作方法，不能创造搜索权限、文件持久化、Python 或图像生成工具。

## 有持久本地工作目录

Codex 桌面/CLI/IDE，以及实际提供同等文件能力的 ChatGPT 桌面环境，可使用完整工作区：读取真实路径，初始化并持续维护普通文件。不同聊天只有都能访问这个目录时才共享课程。命令使用探测到的 Python 3.10+；脚本仅依赖标准库。不要写死 Windows 用户路径或把 CLI 的斜杠命令当作所有桌面入口。

技能资源路径相对本技能安装位置，课程路径相对明确的学习根目录。执行脚本不改变聊天绑定目录，不自动注册项目。显式读取工作区入口，即使宿主尚未自动重新读取刚写入的 AGENTS.md。

## 只有会话文件或沙箱

若 ChatGPT 提供可写会话目录和执行能力，可以运行同样的脚本，初始化时设置 `--storage-mode session`。说明这些文件并未写入用户电脑，也不保证跨新聊天保留。

课程阶段成果或本次结束时，用当前可用文件工具交付真实的课程目录归档和简短恢复说明；归档包括接续状态、实际材料和必要资产，排除活跃锁与临时写文件。另一个聊天先取得归档，检查内容后恢复，不仅传一段含糊总结。不得凭同名文件就覆盖不同课程。

有文件读写却无 Python 时，按课程协议手工维护文件与版本，说明没有运行脚本检查。读取—比较修订号—保存不是完整并发锁；此模式保持单一正式写入者，两个聊天分别交付反馈。

## 只有文本，或参考资源不可读取

仍可采访、解释与研究实际可访问资料。用清楚标记的文本交付简报或材料，说明持久保存能力尚缺。不能声称已经创建本地工作区、执行绘图脚本或自动同步。需要完整文件课程时，具体说明所缺文件能力，并帮助用户携带现有内容进入支持该能力的环境。

技能包虽兼容通用目录标准，普通聊天上传几个 MD 不等于安装、发现全部参考或长期保存。按当前客户端实际提供的技能/插件入口选择；安装与账号权限由宿主处理。API 的技能上传机制不等于 ChatGPT UI 的上传机制。

## 搜索与媒体

有搜索工具就实际检索并打开关键内容。搜索可用不表示本地命令可以下载；通过实际可用途径取得材料并记录失败范围。无法联网且缺少关键资料时不能伪装已全面研究，可先访谈、读取用户文件并列出具体缺口。

有内置图像生成和可视化能力时使用；有数值绘图工具时运行并检查。技能不固定工具内部名字、模型版本或 API 密钥。生成图、数据图与原始图的证据身份分开。交互可用性需实际验证，保留静态或文字替代。

课程无需新服务器、MCP、云数据库或自动化调度即可成立。能力不足的影响要具体，不把整个任务机械拒绝，也不把未完成能力写成已实现。
