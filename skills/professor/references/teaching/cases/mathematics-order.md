# 同一位数学教师，并不总按同一个顺序解释

Auroux 的两节相邻课为“先动机、后定义”这类笼统规定提供了直接的反例。它们都来自多元微积分课程，不需要先诉诸不同学科的差别。

第一课已经做过向量长度、加法和数乘的解释。引入点积时，Auroux 先说明它把两个向量变成一个数，给出计算定义及例子，然后才问：

> “What is it good for? Why would we ever want to do that?”

此时问题所指的运算已经具体，接下来的几何解释回答的是“刚才这个操作为什么有意义”。它不是一份没有动机的定义清单，只是动机没有被强行放到最前面。[官方第一课资源](https://ocw.mit.edu/courses/18-02-multivariable-calculus-fall-2007/resources/18_022007l01/)，研究定位 M-AU01 PDF 第四、五页。

第二课延续点积的应用，随后遇到面积计算的问题。教师先尝试沿已有的几何关系与点积继续走，处理旋转后的向量，最后给得到的表达式一个名字：行列式。新对象在这里从已有计算中出现。[官方第二课资源](https://ocw.mit.edu/courses/18-02-multivariable-calculus-fall-2007/resources/18_022007l02/)，研究定位 M-AU02 PDF 第二至四页。

我对差别的解释是：前一个地方，一个容易操作的定义可以先给听众共同对象；后一个地方，学生刚获得的工具足以承载一段探索。不是“好数学课总从问题开始”，也不是定义优先更好。顺序取决于当时有什么可供理解借力。

## 与 Strang 的对照：重复的东西可以不同

Strang 第一课反复保留同一方程组，改变观看方式；第六课更多通过满足与不满足子空间要求的情形，赋予定义区分对象的力量。这两课的连续性并不靠重复相同开场或相同结尾。[第一课](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/mit18_06s10_l01/)，[第六课](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/resources/mit18_06s10_l06/)；研究定位 M-S01 PDF 第一至九页、M-S06 PDF 第一至三、十至十一页。

Auroux 第一课则有一个很小但有用的语言动作：先说明运算所得是数，随后再次回到对象种类。他还明确提到，简单时似乎显然的区别，在复杂题目里容易忘。这类重复保留了读者在符号中的方向。Strang 的反复换表征与 Auroux 的反复辨对象，都不能简化成“讲三遍”。

数学内容的准确性另有来源和论证要求。本案例研究的只是讲述次序与注意力，不替这些旧转写校勘全部公式，也不把教师一句口头概括当作可直接复制的定理。整理成中文长篇讲述时，板书所承担的对象必须真正可见；伪造“大家现在都看明白了”不会补上它。
