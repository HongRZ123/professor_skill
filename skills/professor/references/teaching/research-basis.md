# 教学资源的依据与限制

整理日期：2026-10-12。这里说明已做研究的身份，不要求每次备课重复整套研究。

领域札记与案例来自对 MIT OpenCourseWare、Open Yale Courses 的课堂文字稿比较：共涉及十四位教师、二十八课，八课全文阅读、二十课选段阅读。比较了同一教师不同课次，也比较了相近领域不同教师。没有听看全部视频、音频和课堂幻灯片，也没有测量学习效果。“优秀公开大学课堂”是选材起点，不是已经证实每段表达最优。

案例保留官方课堂页面、课次和定位。Y/M 开头编号、P 段号、B 时间块以及 PDF 页序是原研究整理定位，不是官方网站通用编号；重新核查时先打开案例里的官方链接，再按课次、文字片段或时间查找。包内不分发整份第三方文字稿，也不依赖原研究电脑的文件路径。

哲学样本不能代表全部欧陆哲学；艺术案例包含建筑与音乐，尚缺同一艺术子领域两位教师对相同内容的充分对照；英文公开课也不能代表所有语言、国家与大学课堂。经验中的“这可能帮助读者……”是上下文分析，除非明确引教师自述，否则不声称知道其备课意图。

## 通用讲述分析的文献基础

下列文献支持理解教学功能和情境判断，不能合并为“全部研究证明本 skill 有效”。阅读范围沿用研究记录，摘要与选段不当作全文。

| 来源 | 实际使用范围 | 在本资源中的作用与边界 |
| --- | --- | --- |
| [Shulman，Those Who Understand，1986](https://www.wcu.edu/webfiles/pdfs/shulman.pdf) | 文件第七、十、十一页及第八页部分 | 学科教学知识、案例和策略判断；理论论述，不是本工具效果实验 |
| [Merrill，First Principles of Instruction，2002](https://mdavidmerrill.wordpress.com/wp-content/uploads/2019/04/firstprinciplesbymerrill.pdf) | 第一至二、四至六页相关部分 | 区分原则与实现、介绍与示范；不照搬阶段流程 |
| [Rosenshine，Principles of Instruction，2012](https://www.aft.org/sites/default/files/Rosenshine.pdf) | 第一至二页、第四页模型示范选段 | 初学者负担与示范；不移植固定练习比例或分钟数 |
| [Collins、Brown、Holum，Cognitive Apprenticeship，1991](https://www.aft.org/ae/winter1991/collins_brown_holum) | 引入、建模、部分指导与反思等 | 让处理问题的理由可见；文字课堂不等于完整学徒制 |
| [How People Learn II，第五章，2018](https://www.nationalacademies.org/read/24783/chapter/7) | Knowledge and Expertise 开头及结论部分 | 已有知识与知识组织；委员会综合，不直接证明课程效果 |
| [Ausubel，1960](https://doi.org/10.1037/h0046669) | 摘要、首页预览 | 先行组织者的有限实验背景；不等于每课必须有故事导入 |
| [Mautone、Mayer，2001](https://doi.org/10.1037/0022-0663.93.2.377) | 摘要 | 关系提示的线索；短篇多媒体实验不能直接推广两小时哲学文字课 |
| [Lee，2009](https://doi.org/10.1016/j.esp.2008.11.001) | 出版方摘要 | 班级条件与开场话语的补充线索，未据此设规则 |
| [Cheng，2012，论文与研究报告](https://ir.lib.nycu.edu.tw/bitstream/11536/99180/1/1002410H009033.PDF) | 摘要、方法、结论选段 | 大学课堂结尾差异；描述性研究，不证明哪种结尾效果最佳 |
| [Jalilifar 等，课堂结尾研究](https://bop.unibe.ch/linguistik-online/article/download/2515/3738/8960?inline=1) | 引入、部分方法、策略与结论 | 保留语言与课堂语境的差别 |
| [CMU Eberly Center，Lectures](https://www.cmu.edu/teaching/designteach/teach/instructionalstrategies/lectures.html) | 主体教学建议 | 目的、关联、过渡等经验；不是原始实验 |
| [Waterloo，Lecturing Effectively](https://uwaterloo.ca/centre-for-teaching-excellence/catalogs/tip-sheets/lecturing-effectively) | 主体教学建议 | 方向、表达与视觉材料；不继承概念数量和时间限额 |
| [Bradbury，2016](https://doi.org/10.1152/advan.00109.2016) | 摘要与公开摘段 | 审视固定注意力时限说法；未读完整全文 |

因此，通用参考谈的是怎样让人进入内容、看见依据、建立联系与形成阶段性认识。它保留教育经验，又把具体顺序交还当前内容。实际课程质量仍要通过完整课次与用户阅读反馈校准。
