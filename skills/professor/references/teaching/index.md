# 教学经验的阅读入口

编写课堂材料时，按当前内容阅读[通用讲述参考](general.md)、相关领域札记或具体案例。这些是帮助判断的经验，不是必须完成的技巧清单，不决定每节课的开场、顺序、段落数、时长或结尾形状。不要把文件标题拼成讲义模板。

当前的课程目的、学习者基础、syllabus、资料和实际反馈决定讲述安排。同一课可以在一个对象上长时间停留，连续几课也可以自然不同；无需为显示变化而变化。原课堂的教学分工不自动适用于当前用户，不借原教师省略某段内容为本课解释不足辩护。

这些窗口只反映现有样本。跨领域主题不需要依次套用多套讲法，其他领域也无需硬塞入某类。参考中没有适合的经验时，依据该领域对象、证据方式与课程需要正常讲述，必要时补查实际课堂。

案例中的举手、学生回应、图像和声音属于原课堂。新材料不能把它们当作当前用户的经历。借鉴教师让注意力落到哪里、为什么在那个地方停留或转向；不要复制现场表演或虚构互动。

研究来源与阅读限制见[依据与限制](research-basis.md)。这些经验没有经过本 skill 的学习效果验证。
