# 可查询的访谈题库

这里有一百个候选问题，按设计决策而非问卷顺序组织。一次只读相关组，选少量问题并依据回答改写、追问。各组的适用条件和每条的追问/跳过提示共同约束使用；数量不是访谈闭合尺度。

| 问题组 | 何时查阅 |
| --- | --- |
| [目的与范围](purpose.md) | 新主题，或目标之间有冲突；已明确的选择跳过。 |
| [基础与前置](foundations.md) | 内容可能依赖旧知识时；不用整套入学测试。 |
| [原材料与来源](reading.md) | 教材、原典、论文或多源阅读会影响课程时。 |
| [课堂阅读体验](experience.md) | 准备确定材料体验时；不预设统一讲课语气。 |
| [理论与理解标准](depth.md) | 深入的含义不明确，或多种理解目标混在一起时。 |
| [练习与反馈](practice.md) | 练习、诊断或私教负担可能影响体验时。 |
| [负担与可用条件](constraints.md) | 可能影响可行性时；不调查无关私人信息。 |
| [持续使用与记录](continuity.md) | 首次约定长期工作方式，或接续出现问题时。 |
| [人文艺术的具体取舍](humanities.md) | 按真实主题挑选，跨领域可与其他组共同使用。 |
| [数学计算机与经验研究](stem.md) | 只选当前主题相关问题，不将领域归类变成课型模板。 |
