# 练习与反馈

适用：练习、诊断或私教负担可能影响体验时。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q051 · 你愿意在课后做哪类尝试：解释、推导、细读、计算、代码还是实验？ | 选择匹配目标的活动 | 不要求每种都做，不默认工程项目 |
| Q052 · 你希望练习附完整解释，还是先留出自行尝试空间？ | 决定答案呈现 | 用户索要解释时不以先尝试为门槛 |
| Q053 · 理解检查对你有帮助，还是容易打断阅读？ | 决定出现位置和频率 | 可以课后自选，不套固定测验周期 |
| Q054 · 你愿意把自己的解释发给私教讨论吗？ | 获得真实理解证据 | 不愿意也可继续课程，状态保留未知 |
| Q055 · 卡住时，你偏好一个提示、换一种解释，还是完整走一遍？ | 调整个别辅导 | 当下请求可覆盖默认偏好 |
| Q056 · 需要写代码时，你希望理解已有代码、补一小段，还是独立实现？ | 决定工程负担 | 主题不需要代码则跳过 |
| Q057 · 实验对你是验证理论、理解现象，还是学习研究方法？ | 避免无目的跑实验 | 区分教学演示与真实支持结论的实验 |
| Q058 · 你怎样愿意反馈一节课：具体疑问、读后感受，还是短的解释尝试？ | 设计低负担反馈入口 | 可以不固定格式，不把沉默当满意 |
| Q059 · 你是否需要定期回看前面的问题，还是只在新课用到时回访？ | 安排复习经验 | 不自动启动提醒或用固定间隔算法 |
| Q060 · 老师发现你的解释有误时，你希望先指出关键差异还是一起定位？ | 校准纠错方式 | 尊重当下请求，不拖延必要事实纠正 |
