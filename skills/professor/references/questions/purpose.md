# 目的与范围

适用：新主题，或目标之间有冲突；已明确的选择跳过。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q001 · 你希望这段学习最先改变什么：能读懂原材料、建立体系，还是判断一个具体问题？ | 决定课程主线与材料角色 | 若多个都重要，比较一节原典细读与一节领域比较的体验 |
| Q002 · 有没有一处你反复遇见却一直无法解释的困难？ | 把抽象兴趣接到真实问题 | 无具体例子不强求，可先研究领域入口 |
| Q003 · 你更希望从一个作者向外展开，还是先建立全景再回到作者？ | 改变覆盖与深读的比例 | 只在两条路径都可能成立时比较 |
| Q004 · 哪些相邻问题很有吸引力，但这次可以暂时不学？ | 形成可解释的边界 | 不知道邻域时由调研建议，不要求用户预先列齐 |
| Q005 · 如果结束时只能保留一种能力，你希望保留哪一种？ | 澄清冲突目标的优先级 | 目标一致时不必制造艰难选择 |
| Q006 · 你期待形成自己的判断，还是先准确重述不同观点？ | 决定比较与论证的深度 | 可分阶段，不能把二者当互斥能力 |
| Q007 · 这是一段有截止日期的学习，还是可以长期展开的课程？ | 影响课程边界与节奏 | 不把没有截止日期等同于无限课程 |
| Q008 · 哪些内容即使很难，你也不希望被略过？ | 识别不可牺牲的核心 | 再核对与时间负担是否冲突 |
| Q009 · 哪些东西你不希望本课默认追求，例如考试、就业或项目？ | 避免偷换学习目的 | 已有明确排除项时直接沿用 |
| Q010 · 你怎样描述一次真正有收获的课：看清关系、跟完论证，还是能处理新问题？ | 找到可讨论的质量尺度 | 用以往体验帮助说明，不强制量化 |
