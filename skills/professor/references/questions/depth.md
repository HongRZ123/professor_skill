# 理论与理解标准

适用：深入的含义不明确，或多种理解目标混在一起时。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q041 · 你希望能复述结论，还是能重建它为什么成立？ | 决定论证与中间步骤 | 两者可有阶段关系，不把背术语当理解 |
| Q042 · 对关键方法，你更在意推导、适用条件还是与替代方法的区别？ | 分配理论篇幅 | 重要条件不因偏好不同而省略 |
| Q043 · 你希望读懂作者的原论证，还是也讨论后人如何修正它？ | 区分历史理解与当前判断 | 由研究确定哪些后续修正重要 |
| Q044 · 你愿意接受哪些暂时黑箱，哪些必须在当前课解释？ | 控制前置递归 | 明确保留任务，不把暂用当永远省略 |
| Q045 · 遇到多个合理解释时，你希望怎样保留自己的判断空间？ | 安排不同观点的声音 | 教师可有理由地判断，不假装所有观点等价 |
| Q046 · 对一个理论，你希望能识别它不适用的情况吗？ | 考虑反例与边界的作用 | 不因选择是就给每课固定反例段 |
| Q047 · 怎样的新问题会让你觉得学到的东西能迁移？ | 选择有意义的迁移情境 | 用户不知道时教师提出候选并解释 |
| Q048 · 你希望区分哪些层次：直观解释、形式论证、经验支持或实现行为？ | 防止混淆证据层次 | 只讨论当前学科实际需要的层次 |
| Q049 · 如果材料中有尚未解决的研究问题，你希望接触到什么程度？ | 确定开放问题范围 | 不将未知包装成课程已经给出答案 |
| Q050 · 结束时你希望能够向谁解释这个主题，他们大概有什么基础？ | 找到表达与理解的参照 | 没有外部受众也可以为自己学习 |
