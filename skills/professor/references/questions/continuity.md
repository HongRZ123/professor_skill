# 持续使用与记录

适用：首次约定长期工作方式，或接续出现问题时。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q071 · 你希望课程放在哪个已有目录或新工作区？ | 绑定实际位置 | 环境和请求已明确位置就核实后使用，不多问 |
| Q072 · 教授和私教会使用同一个目录，还是通过文件交接？ | 决定反馈传递 | 能从现有环境确认则不要求用户解释平台实现 |
| Q073 · 你希望老师长期保留哪些反馈？ | 避免无限个人画像 | 默认保留与教学有关的实际信息 |
| Q074 · 哪些笔记由你自己维护，不希望自动整理？ | 划分写入边界 | 用户笔记默认不默默重写 |
| Q075 · 课程方向改变时，你希望看到受影响课次的说明吗？ | 安排修订沟通 | 重大变更本就需要具体讨论，不变成每次小修审批 |
| Q076 · 如果你只说下一课，是否按既定安排继续？ | 校准接续语义 | 默认可以继续，但不登记掌握 |
| Q077 · 中途搁置再回来时，怎样的定位信息最有帮助？ | 整理恢复入口 | 不因离开时长自动推断遗忘 |
| Q078 · 你需要保留旧版讲义与个人批注之间的对应吗？ | 确定版本阅读需求 | 实质修订仍保留旧版，不为每个小改动复制全库 |
| Q079 · 你希望跨课沉淀哪些参考，例如术语、方法对照或阅读索引？ | 选择真正可复用的材料 | 没有需要不预建空库 |
| Q080 · 如果工具不能跨会话保存，你能接受带归档到新会话的方式吗？ | 选择受限环境的实际方案 | 有本地持久目录时跳过，不能虚构自动同步 |
