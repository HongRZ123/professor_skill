# 负担与可用条件

适用：可能影响可行性时；不调查无关私人信息。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q061 · 一次阅读你大概能连续投入多久？ | 安排一堂完整课的分次阅读 | 每课仍是完整120分钟讲授量，短阅读会话和每周预算都不授权缩短课堂 |
| Q062 · 每周能安排多少课程和课前课后阅读时间？ | 安排每周课数与学习跨度 | 每堂课固定完整120分钟讲授量，周预算不授权缩短单课 |
| Q063 · 是否有某个现实期限影响这段学习？ | 调整范围 | 没有期限不追问工作或生活细节 |
| Q064 · 你主要在电脑、平板还是打印材料上阅读？ | 选择导航与显示 | 不因设备推断用户能力 |
| Q065 · 有没有字体、颜色、声音或交互方面的可访问性需要？ | 保证材料能使用 | 只问功能需要，不要求医学信息 |
| Q066 · 你现在能使用哪些阅读材料或工具？ | 确定真实起点 | 能从环境安全核实时由教师先核实 |
| Q067 · 是否可以运行本地代码，还是希望只读讲解和结果？ | 安排代码与实验 | 不把仅阅读降低为只给概要 |
| Q068 · 资料获取是否限于免费公开内容？ | 筛选可实际使用的来源 | 不默认订阅或购买 |
| Q069 · 图像或实验若需要额外付费服务，你希望先采用现有替代吗？ | 明确服务边界 | 已有限制直接执行，不反复询问 |
| Q070 · 你希望材料都能离线保存吗？ | 决定资产与外部依赖 | 如不能取得全文，说明离线能力的实际缺口 |
