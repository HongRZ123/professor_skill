# 原材料与来源

适用：教材、原典、论文或多源阅读会影响课程时。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q021 · 你希望主要读老师讲义，还是让课堂带你回到原材料？ | 确定阅读分工 | 用预读难文后听课与先听课后回读两种体验比较 |
| Q022 · 有没有必须使用的教材、版本、译本或文档？ | 确定材料约束 | 进一步核对实际能否取得，不默认别的版本同页码 |
| Q023 · 你需要逐段陪读，还是只在关键段落停留？ | 决定细读密度 | 不同课次可以不同，不冻结全局比例 |
| Q024 · 一节课前你愿意准备多少原始阅读？ | 安排真实预习负担 | 尚不确定时用首课样例校准 |
| Q025 · 原材料看不懂时，你希望仍能先进入课堂吗？ | 决定课堂自足程度 | 不将预习完成作为默认开课门槛 |
| Q026 · 资料有分歧时，你希望同时比较，还是先沿一条主线建立理解？ | 安排争议进入时机 | 保留重要分歧，不等于每处都展开辩论 |
| Q027 · 哪些语言的资料你可以直接读，哪些希望提供导读或翻译？ | 决定来源与解释支持 | 翻译不替代核对原文，避免问无关语言经历 |
| Q028 · 你对新版材料的要求是什么：经典基础、当前进展，还是两者的关系？ | 决定时效性研究 | 稳定经典不因年代旧而淘汰 |
| Q029 · 需要付费或无法取得的原文，你已有合法可用副本吗？ | 判断可访问材料 | 没有则研究替代，不默认购买或上传 |
| Q030 · 你希望引用怎样不打断阅读：就近短注、节末来源，还是可展开说明？ | 校准可追溯与可读性 | 关键主张仍要能定位，形式可在样例后改 |
