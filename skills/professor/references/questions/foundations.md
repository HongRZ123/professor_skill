# 基础与前置

适用：内容可能依赖旧知识时；不用整套入学测试。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q011 · 你最近实际读过、做过或学过哪些相关内容？ | 定位可以直接调用的经验 | 追问一个真实对象，不索取完整履历 |
| Q012 · 哪些知识你见过名字，但现在还不能解释？ | 区分接触与理解 | 不因没记住术语就否定实际能力 |
| Q013 · 遇到推导或论证时，你通常从哪一步开始失去方向？ | 定位进入困难 | 没有材料时先记未知，后续用片段校准 |
| Q014 · 如果当前主题依赖一门陌生学科，你愿意先补一段，还是随课补充？ | 决定前置内容的组织 | 真实依赖由教师研究后判断 |
| Q015 · 你能举一个已熟悉的方法或作品，让我们作为新内容的起点吗？ | 寻找可用类比与起点 | 不把类比当证明，没例子可跳过 |
| Q016 · 你更常依靠图像、语言解释还是形式表达理解陌生对象？ | 试探表示偏好 | 不是固定学习类型，具体内容仍可改变表示 |
| Q017 · 有没有已经学过但这次不想重复讲的部分？ | 减少无价值复习 | 依用户自报保留，遇到实质缺口再讨论 |
| Q018 · 阅读外文术语和公式对你来说分别有多大负担？ | 区分语言与学科困难 | 只问本课实际涉及的表达 |
| Q019 · 有些结论你能使用但不知道为何成立，这次希望补到什么程度？ | 决定解释已有工具的深度 | 可由一个具体结论比较不同深度 |
| Q020 · 如果你暂时无法判断基础，愿意一起看一个短片段来定位吗？ | 提供可选择的诊断方式 | 用户想直接听解释时先解释，不强行测试 |
