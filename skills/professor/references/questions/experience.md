# 课堂阅读体验

适用：准备确定材料体验时；不预设统一讲课语气。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q031 · 你更愿意一口气读完整课，还是在完整文件中自行分节读？ | 决定导航与分节方式 | 两者都保持完整讲授，不拆成强制问答碎片 |
| Q032 · 你想保留老师自然讲述的语气，还是更接近精心整理的讲义？ | 校准语言与口语感 | 不要用赘词模仿录音，不等于缺少理论深度 |
| Q033 · 什么样的过渡会让你容易迷路：突然换例子、跳到公式，还是换观察尺度？ | 识别连贯性问题 | 有具体阅读片段时优先讨论片段 |
| Q034 · 你希望老师什么时候停下来问你，什么时候直接把解释讲完？ | 设定互动边界 | 教授正文默认完整，个别辅导另行处理 |
| Q035 · 课堂中的假设性提问需要留思考空间，还是紧接着解释更适合你？ | 调节阅读节奏 | 不虚构你的回答或强制等待 |
| Q036 · 图表对你最有帮助的情况是什么？ | 辨认视觉用途 | 由内容决定是否制作，不固定每课数量 |
| Q037 · 如果一个问题值得长时间停留，你更担心解释不足还是失去整体方向？ | 平衡局部深度与定位 | 两者都可能需要，比较具体段落再定 |
| Q038 · 哪些讲课风格让你难以投入，例如过多比喻、定义堆砌或过度铺垫？ | 记录明确表达偏好 | 不自动变成所有主题禁用某种方法 |
| Q039 · 阅读长篇材料时，目录、术语索引、旁注或打印哪项更有用？ | 决定实际阅读支持 | 先做最有用的形式，不全部构建 |
| Q040 · 完整课堂分次阅读时，你希望怎样安排停点和接续？ | 校准阅读组织与课程频率 | 完整120分钟讲授量不因阅读分次缩水；用户明确另要短讲才改变规格 |
