# 人文艺术的具体取舍

适用：按真实主题挑选，跨领域可与其他组共同使用。

以实际学习场景比较体验，解释选择会改变什么；问题措辞可以调整，不要求用户选择固定选项。

| 编号与参考问法 | 会影响的设计 | 追问或跳过的判断 |
| --- | --- | --- |
| Q081 · 阅读原典时，你更关注作者当时的问题，还是它对今天问题的意义？ | 安排历史语境与当代应用 | 二者可并置，但需说明语境变化 |
| Q082 · 你希望细看原文措辞、译名，还是先理解整体论证？ | 决定语言细读的入口 | 重要译名分歧仍需说明 |
| Q083 · 不同解释传统之间，你已有特别感兴趣的一条吗？ | 选择有依据的主线 | 没有就由研究呈现候选，不让用户提前当专家 |
| Q084 · 读文学作品时，你希望课堂更靠近文字、叙事结构还是历史条件？ | 调节分析距离 | 作品本身可以要求多种距离，避免固定每课分栏 |
| Q085 · 你希望先完整接触作品再分析，还是在课堂中逐渐进入？ | 安排原对象和讲述的关系 | 考虑作品长度与取得条件 |
| Q086 · 看艺术作品时，最希望老师帮助你注意到什么？ | 决定图像和观看支持 | 没有概念词也可描述困惑 |
| Q087 · 音乐或表演内容能实际听看，还是目前只能读文字？ | 确定感官材料可用性 | 没有媒体不假装用户已听到演示 |
| Q088 · 哲学论证中，你希望老师公开自己的判断到什么程度？ | 区分立场与介绍 | 教师判断须给理由，不能遮蔽异议 |
| Q089 · 历史学习中，你更关心过程、史料解释还是争议如何形成？ | 决定证据和叙述比例 | 不把一条时间线当完整因果解释 |
| Q090 · 创作或表演练习是否属于这次目标？ | 区分理解作品与实践训练 | 不因学艺术就强制创作，也不默认只讲理论 |
