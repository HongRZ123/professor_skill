# 图像、图表和交互材料

视觉材料是完整课堂的默认组成部分。备课时主动识别本课适合看见的关系、比较、过程与具体对象，制作并分布在有关讲述中，不能只把能力列成“可用时考虑”。不按课次固定图数，但不能用文字也能说明为理由取消所有图，也不以末尾一张总览图代替丰富的课堂视觉。

| 表达需要 | 可采用的方式 | 核对重点 |
| --- | --- | --- |
| 原创教学场景、空间想象、插画 | 宿主内置图像生成；有提供的图像技能时遵循其实际用法 | 实际查看输出，核对标签、关系和用途，标记教学性生成 |
| 原作、史料、论文或实验原图 | 合法可取得的原始图像、用户材料 | 来源、版次、裁剪与标注；生成图不代替证据原图 |
| 数值关系、数据、函数或仿真 | 可用 Python/其他精确绘图工具 | 数据、单位、参数、代码及图一致；合成数据明确说明 |
| 关系、结构与流程 | Mermaid、SVG 或适合的绘图代码 | 连线语义、层级和可读性；不能把相邻画成因果 |
| 需要操控参数的变化 | 宿主可视化能力或独立 HTML | 实际运行交互，并提供静态或文字替代 |

生成工具和数据绘图不可互相替代。存在有益的情境、空间或艺术性说明时实际调用图像生成能力；关系、论证与数据则制作精确图表。是否使用生成插图由教学对象决定，不强制每课两种工具都调用。精确公式、坐标和关系不要交给插画模型凭外观画对。工具已可用就直接完成适合的制作，不只写出未来提示词或图的设想。

围绕每幅重要图写出充分讲解：它接续哪个问题、如何读取标签或比较、哪些变化重要、可得什么认识及不能推断什么。讲义要实际嵌入图像或提供能打开的相对链接；行内 Mermaid 需真实源码、定位及宿主展示核验。图文件存在而正文没有带读，不算完成视觉教学。

若某图容易造成误解，修正其表示和讲解或换成更合适的视觉对象。例如不应给物自体编造空间位置，但仍可画论证关系、概念适用范围或原文层次。一个比喻不适合画，不等于整堂哲学课无需视觉。禁止为数量填装饰图。

图像生成后使用工具返回的真实文件或媒体，不猜默认路径。将正式引用的可保存资产放入课次版本目录，保留来源或生成方式，并在正文具体讲解如何看。若只能预览而无法取得文件，如实报告，不登记为已落盘。编辑已有图使用实际可用且被授权的图像编辑方式。

看过输出再记录 `checked: true`。出错时有针对性修订，无法可靠做对就采用更简单表示；不把占位符当正式图片。HTML、SVG 和 Markdown 的展示分别检查，Mermaid 不保证每个客户端自动渲染。

先用已授权宿主能力，不为每张普通教学图询问。新增服务、费用、凭证或上传用户材料到不同服务，按实际授权处理；不能静默切换。缺少某绘图库先检查现有环境，可用简单 SVG 表示的关系无需安装大型依赖。

数据图保存数据和脚本；交互保留 fallback 文件；跨课资产保存明确版本。资产记录见[文件协议](course-files.md)。不默认做网站、部署服务或为展示而削弱课堂正文。
