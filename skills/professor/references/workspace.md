# 建立和维护学习工作区

工作区与安装技能分开。用户或应用已提供的新空目录就是课程根目录，不再套无用目录；已有教材留原位。混合目录只使用已明确的课程位置，不能接管无关项目。已有本技能状态就恢复；同名但未知用途的文件先识别，不能覆盖。

初始化创建 AGENTS.md、COURSE.md、state.json；已有 AGENTS.md 保留，并追加简短入口。主题已知时写 intake/notes.md；未知则等待主题。初始化与本轮访谈一起完成，不把文件准备做成额外审批轮次。必要命令见[文件协议](course-files.md)。

目录随真实内容形成：

```text
AGENTS.md / COURSE.md / state.json
intake/                 回答、需求及用户决定
research/               研究报告、结构、来源记录、原材料和阅读笔记
materials/              已选教材与文件、可用入口、逐课阅读地图与准备状态
syllabus.md             当前课程安排
orientation.md          课程使用说明
lessons/L01/            准备、制作记录与待发布元数据
lessons/L01/v1/         正文、资产、补充与发布元数据
reference/              确有跨课价值的教学参考
assets/                 有版本的跨课复用资产
learning/               真实学习记录、问题、用户笔记
handoff/from-tutor/     私教追加的反馈
history/                已发布版本快照及实质变更历史
changes.md              教授维护的修订与反馈处理结果
```

AGENTS.md 只作稳定入口，不保存不断增长的个人画像；COURSE.md 是阅读导航；state.json 是阶段与发布指针，不能重复存整套课程。脚本只更新 COURSE.md 标记区，用户说明放在区外。JSON 不是用户必须阅读的界面。

原资料、研究笔记、学生课程材料、课堂和学习证据分开。materials 在研究和大纲确定时实际填充，不到用户追问才准备。reference 中术语存在不代表用户掌握，也不强制不同译本统一术语。assets 有实际跨课复用价值才提取；改动另存版本，避免改变旧课。用户笔记不自动整理重写。

确认需求、读完关键选段、写完一段长课或收到实质反馈后及时保存；每轮结束核对下一步。没有新事实可不加记录。写作断点放 build.md，来源问题放研究笔记，不能塞进用户学习档案。

恢复时定位根目录，读入口和状态，再按请求读取有关文件，不扫全部历史材料。AGENTS.md 的自动发现取决于宿主和启动位置，技能仍须显式恢复。状态不一致时核对真实产物和决定记录，不凭最后修改时间猜。

初始写入日志 `.professor-init.json` 支持中断后再次 init；脚本遇到用户改动会停止并保留文件。写锁只覆盖短时保存。锁残留时先检查其中 PID 与是否仍有写入任务，确认进程已结束才手工移除该锁文件；脚本不按时间自动删锁。

内部引用保持相对路径，课程身份不绑定机器路径。整体复制后核对外部教材和工具。历史目录不是异地备份；需要时沿用用户的目录备份方式，不强制 Git、数据库或云服务。技能升级只更新技能，不删课程。
